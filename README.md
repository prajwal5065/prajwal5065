### Featured Projects

**[MAP — Multi-Agent AI Automation Platform](https://github.com/Yad4o/MAP)**
Planner → Executor → Analyzer → Memory pipeline orchestrated with LangGraph stateful graphs. FAISS/Chroma-backed RAG memory per user, a ReAct executor loop with real tools, and a confidence-scored evaluation stage that re-executes low-confidence runs. Circuit breaker over all LLM calls with a BentoML-served fallback model, plus RBAC and observability via Prometheus and Grafana.
`LangGraph` `FastAPI` `Celery` `Redis` `PostgreSQL` `FAISS` `BentoML`

**[SRS — Automated Support Resolution](https://github.com/Yad4o/SRS)**
Confidence-based decision engine that auto-resolves support tickets above a set threshold or escalates them to a human agent. Uses TF-IDF similarity search to reuse solutions from resolved ticket history instead of starting from scratch. Built with RBAC, JWT auth, and a layered, test-covered architecture.
`FastAPI` `SQLAlchemy` `TF-IDF` `PostgreSQL`

**[RepoMind AI](https://github.com/prajwal5065/RepoMind-AI)**
RAG-based repository intelligence tool that chunks and embeds a codebase for semantic search and AI-powered Q&A. Went through a full security and architecture audit that surfaced issues like path traversal and CORS misconfiguration, followed by iterative fixes to the retrieval pipeline for better result quality.
`FastAPI` `Next.js` `FAISS` `RAG`

**[Commercial Area Intelligence Engine](https://github.com/prajwal5065/Commercial-Area-Intelligence-Engine)**
Multi-agent B2B lead-generation pipeline with five coordinated agents handling collection, enrichment, validation, and scoring of commercial businesses. FastAPI and SQLite/Supabase power the backend, with a React/TypeScript frontend on top. Includes adaptive concurrency and provider health scoring to keep the pipeline resilient.
`FastAPI` `React` `TypeScript` `SQLite` `Supabase`

**[Persona Twin](https://github.com/prajwal5065/Persona-Twin)**
A RAG-based digital twin that retrieves from a personal knowledge base to answer and respond in an individual's own style. Combines vector search over stored content with generation so responses stay grounded in real material rather than generic output.
`Python` `RAG` `Vector Search`

**[MediBot AI](https://huggingface.co/spaces/Prajwal4107k/My-Medical-AI-Assistant)**
TinyLlama-1.1B fine-tuned on medical Q&A data using QLoRA/PEFT for efficient, low-resource fine-tuning. Deployed as a live Gradio app on Hugging Face Spaces for real-time inference, aimed at making a basic medical Q&A assistant accessible without heavy compute.
`Python` `QLoRA` `PEFT` `Gradio`
